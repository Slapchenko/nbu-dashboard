# Дашборд банківської системи України — позиція Оксі Банку

Повністю безкоштовний набір: два Python-скрипти (лише стандартна бібліотека, без `pip install`)
та один HTML-файл, який відкривається у будь-якому браузері й працює офлайн.

```
nbu_fetch.py            завантажує відкриті дані НБУ (API), кешує їх у raw/, нормалізує у data/*.csv
build_dashboard.py      рахує рейтинги, частки, ROA/ROE і збирає dashboard.html
dashboard_template.html шаблон дашборду (правити тут, якщо хочете змінити вигляд)
dashboard.html          готовий дашборд — саме його відкриваєте / надсилаєте колегам
```

## Швидкий старт

```bash
python3 nbu_fetch.py            # ~5 хв: тягне дані з 01.01.2021 по поточний місяць
python3 build_dashboard.py      # збирає dashboard.html
```

Далі просто відкрийте `dashboard.html` подвійним кліком.

Повторний запуск не перекачує все заново: сирі відповіді API лежать у `raw/`, оновлюється лише
остання звітна дата. Раз на місяць достатньо виконати ті ж дві команди.

### Корисні параметри

```bash
python3 nbu_fetch.py --start 20180201        # уся доступна історія по банках
python3 nbu_fetch.py --refresh-last 3        # перекачати 3 останні звітні дати
python3 nbu_fetch.py --mock                  # демо-дані без мережі (для перевірки)
python3 build_dashboard.py --bank "оксі"     # який банк у фокусі
python3 build_dashboard.py --list-indicators # усі показники, які реально віддає API
```

## Джерела даних (усе — відкриті дані НБУ, без ключів і реєстрації)

| Набір | apikod | Що дає | Розріз |
|---|---|---|---|
| Показник фінансової звітності | `banksfinrep` | активи, зобов'язання, капітал, кредити, кошти клієнтів, фінрезультат | по кожному банку |
| Основні показники діяльності банків | `basindbank` | кількість банків, активи, капітал, ROA, ROE | система |
| Кредити за категоріями боржників | `klk` | портфель, **кредитний ризик** (з 2021) і **непрацюючі кредити** (з 04.2026) | по кожному банку |
| Процентні ставки НБУ | `key` | облікова ставка, ставки овернайт | система, щоденно |
| Офіційний курс валют | `exchange` | курс USD/EUR на дату | система |
| Показники валютного ринку | `kursf` | середньомісячний курс, обсяги операцій | система |
| Процентні ставки депозитних корпорацій | `mir` | ринкові ставки за новими кредитами й депозитами | система |
| Обороти і залишки на рахунку | `osb` | **портфель наданих гарантій** (рахунок 9000) | по кожному банку |

Перевірено окремо: набори `ekn` (нормативи Н1–Н12, LCR), `fsi` і `sklrk` НБУ більше не оновлює —
останні дані вересень 2022 і березень 2021 відповідно. Тому пруденційних нормативів у дашборді немає.

Формат виклику: `https://bank.gov.ua/NBUStatService/v1/statdirectory/{apikod}?period=m&date=YYYYMMDD&json`

Рейтинг Оксі Банку рахується саме з `banksfinrep` — це єдиний відкритий набір НБУ, де показники
подані окремо по кожному банку. Набір `basindbank` (той, що описаний у вашому файлі `Data_set_fields_BS3.pdf`)
даних у розрізі банків не містить, тому він у дашборді відповідає за контекст «як почувається система загалом».

## Показники

Набір `banksfinrep` кодує показники як `BS1_*`
([офіційний довідник](https://bank.gov.ua/admin_uploads/article/Data_set_fields_BS1.pdf)).
У перемикачі вони згруповані за смислом:

- **Баланс** — чисті активи (основа рейтингу), загальні активи до резервів, зобов'язання, резерви
- **Капітал** — власний капітал, статутний капітал
- **Ресурси** — кошти клієнтів, кошти юросіб і НФУ, кошти фізосіб, кошти на вимогу (окремо юр/фіз),
  кошти банків, субординований борг
- **Кредити** — кредити клієнтам (валові й за мінусом резервів), юрособам, фізособам
- **Активи** — готівка та еквіваленти, кошти в інших банках, ОВДП
- **Доходи і витрати** — процентні доходи й витрати, чистий процентний і комісійний дохід,
  комісійні доходи, всього доходів і витрат, адміністративні витрати, зарплата, відрахування
  до резервів, прибуток після оподаткування
- **Коефіцієнти** (розрахункові) — капітал/активи, чиста процентна маржа NIM, витрати/доходи CIR,
  покриття кредитів резервами, кредити/депозити LTD, частка коштів на вимогу, ліквідні активи/активи

Коефіцієнти з показників «з початку року» (NIM) приводяться до річного виміру.
Для відсоткових показників частка ринку не рахується, а зміна показується в процентних пунктах;
для CIR і частки непрацюючих активів № 1 у рейтингу — найнижче значення.

**Якість портфеля.** Набір `klk` містить три різні речі: сам портфель (`Klk_UO`, `Klk_FO`),
кредитний ризик — очікувані втрати (`Klk_Ryz_*`) і непрацюючі кредити (`Klk_*_NPL`).
Непрацюючі кредити в розрізі банків НБУ почав публікувати лише з 01.04.2026, тому довгу
історію якості портфеля показує саме кредитний ризик — обидва показники йдуть на одному
графіку в блоці «Якість кредитного портфеля» і обидва є в перемикачі показників.

**Гарантії.** Портфель наданих гарантій = залишок позабалансового рахунку 9000 «Надані гарантії»
(поле `t025=1` у наборі `osb`, підсумовано за гривнею та валютою). Увага: у відповіді API кожен
залишок приходить двічі — скрипт прибирає дублікати, інакше портфель був би вдвічі більшим.
Це та сама методика, за якою
рейтинг гарантій рахують НБУ й Асоціація українських банків. Авалі за рахунком 9003 сюди не входять —
щоб додати їх або інші позабалансові статті, допишіть номер рахунку в `GUAR_ACCOUNTS`
у `build_dashboard.py`: дані по рахунках 9003, 9020, 9023, 9122, 9129, 9031 вже завантажуються.

**Важливо про структуру даних.** У відповіді API кожен показник розбитий на кілька рядків за полем
`r034` (вид валюти) — скрипт їх підсумовує. Поле `gr_bank` дає групу банку за класифікацією НБУ;
розшифровку кодів скрипт визначає за складом груп. При кожному збиранні друкується перевірка:
чисті активи = зобов'язання + капітал.

## Що показує дашборд

Блоки йдуть у логіці «де ми → що змінилось → як ростемо → з ким поруч → чому такий результат →
як влаштований баланс → увесь ринок»:

1. **Плитки** — чисті активи, капітал, кошти юросіб і НФУ, кошти фізосіб, кредити (усього, юр-, фіз-),
   прибуток, рентабельність: значення, місце в рейтингу, частка ринку, приріст м/м і р/р.
2. **Місце в рейтингу на кожну звітну дату** і **динаміка показника**.
3. **Хто кого обігнав** — зміни позицій за місяць і за рік з поіменними списками.
4. **Динаміка проти конкурентів і системи** — індекс, перша дата = 100.
5. **Приріст рік до року в пір-групі**.
6. **Пір-група: банки близького розміру** — таблиця з прокруткою навколо свого банку.
7. **Порівняння лоб у лоб** — типово підставляється найближчий сусід у рейтингу.
8. **З чого склався фінансовий результат** (водоспад) і **дохідність активів проти вартості фондування**.
9. **Структура активів** і **структура пасивів** проти медіани пір-групи — двома окремими графіками,
   у кожного своя легенда.
10. **Топ-25 банків** на дату, під графіком — таблиця з усіма банками.
11. **Банківська система загалом**.

Керування: угорі праворуч — **Завантажити звіт**, **Оновити** (перечитує файл, якщо дані щойно
перезібрали) і перемикач теми. Під заголовком — банк (згрупований за класифікацією НБУ, свій окремо
вгорі), звітна дата, перемикач місяць/квартал, показник і розмір пір-групи.

**Завантажити звіт** відкриває довідку для Правління на одну сторінку A4: логотип і дата, шість
ключових цифр з місцями в рейтингу, три графіки (позиція, динаміка проти пір-групи, водоспад
фінрезультату) і п'ять висновків, які скрипт формулює сам — рух у рейтингу, темп проти пір-групи,
звідки прийшли ресурси, прибутковість проти системи, найбільше відхилення коефіцієнтів. Кожен
висновок має позначку ФАКТ / ДОБРЕ / УВАГА / РИЗИК. Кнопка «Зберегти як PDF» відкриває діалог друку
(Cmd+P теж працює, коли довідка відкрита).

Окремі блоки можна вимкнути при збиранні:
`python3 build_dashboard.py --features waterfall,spread,movers` (доступні: waterfall, spread, movers,
structure, ltm, compare, period, board).

## Логотип

У комплекті вже лежить `logo.png` — логотип ОксіБанку, обрізаний по краях і підготовлений під
екрани з високою щільністю пікселів. Він вшивається всередину HTML, тому дашборд лишається
самодостатнім і працює офлайн.

Замінити: покладіть свій `logo.png` (або `logo.svg`, `logo.jpg`) поруч зі скриптами, або вкажіть
шлях: `python3 build_dashboard.py --logo /шлях/до/файлу.png`. Якщо файлу немає взагалі, скрипт
один раз завантажить логотип із сайту банку.

## Якщо щось пішло не так

**«не вдалося розпізнати поля»** — НБУ зрідка змінює назви полів у відповіді API.
Скрипт розпізнає їх автоматично, а звіт про фактичну структуру пише у `data/_schema_report.txt`.
Надішліть цей файл — доналаштуємо мапінг за хвилину.

**Показник не знайшовся** (`показник '...' не знайдено`) — подивіться реальний перелік:
`python3 build_dashboard.py --list-indicators`, знайдіть потрібний код і додайте у файл
`metrics_override.json` поруч зі скриптами:

```json
{ "assets": "точний_код_з_API", "dep_retail": "інший_код" }
```

**Одиниці виміру** — скрипт сам звіряє суму активів усіх банків з агрегатом НБУ і, якщо дані
приходять у тис. грн, переводить їх у млн грн (у логу буде відповідне повідомлення).

**Немає даних на останню дату** — НБУ публікує звітність із лагом; на 1-ше число поточного
місяця дані з'являються приблизно за 3–4 тижні. Порожня остання дата — це нормально.

## Автоматичне оновлення

### Варіант А. GitHub Pages — постійне посилання для колег (рекомендовано)

У комплекті вже є `.github/workflows/update-dashboard.yml`: GitHub сам 5-го і 20-го числа кожного місяця
тягне свіжі дані НБУ, перезбирає `index.html` і публікує його. Ваш комп'ютер може бути вимкнений.
Покрокова настройка — у PDF-інструкції (частина 3). Коротко:

1. Створити **публічний** репозиторій на github.com.
2. Завантажити туди всі файли комплекту разом з папкою `.github` (папки `raw/` і `data/` — не треба).
3. Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.
4. Actions → «Оновлення дашборду НБУ» → **Run workflow** (перший запуск вручну).
5. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

Посилання: `https://ваш-логін.github.io/nbu-dashboard/`

### Варіант Б. Локально за розкладом

macOS/Linux, оновлення 5-го числа щомісяця о 9:00 — `crontab -e`:

```
0 9 5 * * cd /шлях/до/nbu_dashboard && /usr/bin/python3 nbu_fetch.py && /usr/bin/python3 build_dashboard.py
```

## Обмеження, про які варто пам'ятати

- Це дані **фінансової звітності**, а не пруденційної: нормативів капіталу (Н1, Н2), ліквідності
  (LCR, NSFR) та частки непрацюючих кредитів (NPL) у цьому наборі немає — НБУ публікує їх
  окремими файлами на сторінці «Наглядова статистика».
- Фінансовий результат подається наростаючим підсумком з початку року; ROA/ROE в дашборді —
  розрахункові (приведення до річного виміру), тому можуть відрізнятися від офіційних цифр НБУ,
  які рахуються за середніми залишками.
- Квартальні дані (`period=q`) містять коригуючі проводки й тому «чистіші» для порівнянь рік-до-року;
  за потреби це вмикається одним параметром — скажіть, додам перемикач.
